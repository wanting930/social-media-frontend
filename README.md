# 社交媒體平台 (Social Media Platform)

一個基於 Vue 3 + Vite 的前端社交媒體專案，提供用戶註冊、登錄、發文、評論等功能。

## 環境要求

- **Node.js**: 18+
- **npm**: 9+（或使用 pnpm/yarn）
- **Vue**: 3
- **Vite**
- **瀏覽器**: 支援現代 ES 模組的瀏覽器，如 Chrome、Edge、Firefox、Safari
- **後端 API**: 本專案預設串接 `http://localhost:8080`

## 技術棧

- Vue 3
- Vite
- JavaScript
- Fetch API
- CSS

## 安裝與執行

安裝相依套件：

```sh
npm install
```

本機開發模式啟動：

```sh
npm run dev
```

編譯打包（生產環境）：

```sh
npm run build
```
